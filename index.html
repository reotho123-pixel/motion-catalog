这是什么

把 app-interaction-design skill 里全部 — 条交互与动效整理成索引：交互模式、质感动效、加载、浮层、导航、展开、下拉选单、图表、形态变化、文字动效。

每条都带「适用 / 实现约束 / 验收」三段，可以复制成请求直接发给 AI。

三种找法

记得名字 → 搜索页直接搜，支持口语词（搜「弹窗」能找到模态对话框，搜「打字」能找到打字机）。

只记得想要什么 → 按需求页，用大白话找。

想整体过一遍 → 目录页按分类筛选，或只看「已实测」。

两个可运行演示页

skill 自带两份手机触摸优先的演示页，浏览器直接打开就能玩：

demo-10-interactions.html demo-8-effects.html
